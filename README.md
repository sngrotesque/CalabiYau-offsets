# CalabiYau offsets

这是一个公开披露游戏《卡拉彼丘》的偏移量的仓库。  

## 使用

`master` 分支永远是最新版本，到 [分支](https://github.com/sngrotesque/CalabiYau-offsets/branches) 去找你需要的版本。  
没有的话自行使用dump工具获取。

没有新手教程，不欢迎新手。  
就这样。

## 分支

分支永远使用 `{version}-update-{date}` 这样的格式，比如 `v1.18.1.5-update-20260915`，其中`{version}`是当前游戏的版本号，`{date}`是游戏更新日期。

## 其他

本仓库不处理《Strinova》（也就是国际服）的任何事情，想要国际服的偏移量的话。  
规矩你懂的，想要你得自己去拿。

由于本仓库的特殊性，可能随时消失，且用且珍惜。

- 怎么知道现在是什么版本？

（只限于启动器）点击右上角的设置，然后点“关于”，就可以看到游戏版本。  
不过它只会显示最新的游戏版本。
